# 캣츠킹덤 · Cats Kingdom

고양이 왕국에서 장난감과 간식을 맞추는 한국어 매치 3 퍼즐입니다. 외부 게임의 이미지·음악·레벨 데이터 없이 직접 제작했습니다.

## 실행

정적 웹사이트입니다. Node.js 의존성 설치 없이 프로젝트 폴더에서 `python3 -m http.server 4180` 후 http://localhost:4180 에 접속하세요. JavaScript 모듈을 사용하므로 파일을 직접 더블클릭하는 대신 HTTP 서버로 실행합니다.

## 초기 버전

- 8×8 판, 6종의 자체 SVG 장난감, 클릭·스와이프·키보드 조작
- 누른 조각과 이웃 조각이 손을 따라 움직이는 드래그, 방향 고정, 잘못된 교환 복귀, 포인터 이탈·취소 처리
- 20개 스테이지 순차 해금, 4개 지역, 별·최고 점수 브라우저 저장
- 3개 매치, 4개 줄무늬, ㄱ/ㅗ자 깜짝 상자, 5개 무지개, 6가지 특수 조합과 연쇄
- 수집·발자국·상자·간식 배달 목표, 두 겹 장애물과 끈
- 판마다 냥펀치 2회, 섞기 1회, 이동 +3 1회. 결제·광고·생명 제한 없음
- 무료 힌트, 막힌 판 자동 섞기, 선택 가능한 효과음

스테이지 데이터는 `engine.js`의 LEVELS에서 관리합니다. 초기 20판 이후 플레이 검증을 거쳐 장기적으로 1,000판까지 확장할 예정입니다. 난이도는 목표·색상 수·장애물·이동 제한으로 설계되었으나 실제 이용자 기반 난이도 조정은 필요합니다. 목표량과 장애물 배치는 초기 버전이며 배치는 재시작할 때 달라집니다.

별은 성공 시 남은 이동이 기본 이동의 40% 이상이면 3개, 15% 이상이면 2개, 그 외 1개입니다. 보조 이동도 남은 이동에 포함됩니다. 남은 이동의 자동 폭발 보너스는 아직 구현하지 않았습니다.

저장은 이 브라우저의 localStorage를 사용합니다. 계정 동기화와 플레이 중인 판의 중간 저장은 없습니다. 글꼴을 불러올 수 없을 때는 시스템 글꼴로 표시됩니다.

## 검증

Node.js 18 이상에서 `npm test` 또는 `node --test tests/*.test.js`.

## 게임 화면 업데이트

스테이지마다 20개의 서로 다른 고정 판 모양을 적용합니다. 재도전할 때 판 모양은 유지되고 일반 조각과 장애물 배치는 다시 생성됩니다. 빈칸이 있는 열의 조각은 빈칸을 건너 아래의 유효 칸으로 떨어집니다. 모바일 플레이 화면은 화면 높이에 맞게 조절하며 지도·도움말은 별도 창으로 열립니다. 특수 조각은 방향별 로켓, 선물 상자, 무지개 방울로 구분합니다. 제거 강조와 거리별 낙하·착지 애니메이션을 적용했습니다.
